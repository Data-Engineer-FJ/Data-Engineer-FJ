# 🏗 Proyecto Principal

## AWS Modern Data Lakehouse Platform

Diseño e implementación de una plataforma moderna de Ingeniería de Datos basada en Arquitectura Medallion (Bronze, Silver y Gold).

### Arquitectura

```text
Fuentes de Datos
        │
        ▼
Amazon S3 (Bronze)
        │
        ▼
AWS Glue + PySpark
        │
        ▼
Silver Layer
        │
        ▼
Gold Layer
        │
        ▼
Amazon Athena
        │
        ▼
Amazon QuickSight
```

### Tecnologías

- Amazon S3
- AWS Glue
- AWS Glue Catalog
- Amazon Athena
- Amazon QuickSight
- PySpark
- Terraform
- GitHub Actions
- Great Expectations
